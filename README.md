# Sistema escolar

Programa de ejemplo para la clase de Programación II.
Registra alumnos, los guarda en un archivo de texto y los
vuelve a cargar.

## Cómo se corre

```
python main.py
```

## Archivos

- `modelo.py` — la clase `Alumno`
- `almacen.py` — guarda y lee `datos.txt`
- `sistema.py` — la lógica del sistema
- `main.py` — el programa que se ejecuta

## Qué genera

Crea el archivo `datos.txt` en la carpeta donde se corre,
con un alumno por línea separado por punto y coma.
